## 🤖 Featured Projects

### 1. Crop Row Detection
> *ROS2 package for autonomous agricultural navigation*

A ROS2 package that detects crop rows in real time using computer vision techniques and estimates their orientation to guide autonomous navigation in agricultural fields. The system integrates with odometry and TF to provide reliable directional information to the robot's navigation stack.

**Technologies:** ROS2 · C++ · OpenCV · TF · Odometry

---

### 2. Autonomous Navigation Architecture
> *Modular autonomy framework for robotic systems*

A modular autonomy system designed for robots, built around state machines, delegate patterns, and an event-driven architecture. The framework provides a flexible and extensible foundation for implementing complex autonomous behaviors while keeping components decoupled and maintainable.

**Technologies:** C++ · Robotics Software Architecture · Event-Driven Systems · State Machines

---

### 3. UDP Video Streaming
> *Real-time video transmission optimised for embedded systems*

A lightweight, real-time video streaming system built with OpenCV and UDP, designed to minimise latency and resource consumption on embedded Linux platforms. The system is suitable for remote monitoring and teleoperation applications in robotics.

**Technologies:** C++ · Python · OpenCV · UDP · Embedded Linux
